# 启动 logo 更换（logo 分区）

ABL 开机从 `logo` 分区读位图显示：开机 logo、fastboot 界面、充电画面。

## 屏幕与位图规格

- 面板分辨率 **1080x2244**（竖屏）。
- 位图必须是**标准 BMP**：54 字节头部、24bpp、BI_RGB 无压缩、底向上（bottom-up）。
- 全屏位图字节数 = 54 + 1080×3×2244 = 7,270,614。

## 分区结构

`logo` 分区（32 MiB）布局：

| 偏移 | 内容 |
|------|------|
| 0x0000 – 0x3FFF | 全零 |
| 0x4000 | 魔数 `LOGO!!!!`（8 字节） |
| 0x4008 | 10 个 u32 小端整数：**前 5 个是偏移、后 5 个是大小**，单位都是 512 字节块（大小 = ceil(位图字节数 / 512)） |
| 0x4200 起 | 5 张 BMP，各自占用大小字段指定的槽位，位图末尾到槽位末尾补零 |

注意：魔数后第一个偏移量低字节恰好像是第 5 个 `!`（例如 0x21），hex 查看易误读成 `LOGO!!!!!`，实际只有 8 字节。

## 五个槽位

| 槽 | 尺寸 | 用途 |
|----|------|------|
| 0 | 1080x2244 | 开机 logo |
| 1 | 1080x2244 | fastboot 界面（清空后 fastboot 退回文本模式，显示更多信息） |
| 2 | 300x2160 | 充电画面 |
| 3 | 1080x2244 | 开机 logo（解锁态显示的那份） |
| 4 | 1080x2244 | "The system has been destroyed"（系统损坏画面，建议保留） |

## 操作流程

1. **备份**：取官方固件包 `logo.img`，或 `dd` 整个 logo 分区（前 31,044,608 字节有效、其余零填充）。
2. **解析**：按上表读头部 5 组偏移/大小（×512），用 `binwalk` 或脚本定位 BMP；确认读出的 BMP 尺寸是 1080x2244（以分区为准，别信 dtb 面板 compatible——本机 dtb 借用了别型号面板驱动）。
3. **制作新图**：任意图像工具（Krita/GIMP/Python），画布 1080x2244、黑底，导出 24bpp BMP；尺寸/位深须与原槽一致，否则偏移错位、显示花屏。
4. **重打包**：原位替换对应槽位、剩余补零；头部和别槽不动；移除某图 = 整槽清零；写完逐字节 diff，确认只改目标槽。
5. **刷入**：进 fastboot（关机后 power + vol-），`fastboot flash logo logo-new.img` 再 `fastboot reboot`。

## 备忘

- fastboot splash（槽 1）清空后，进 fastboot 显示带版本/变量信息的文本界面。
- 分辨率以分区 BMP 头和运行时 framebuffer（`cat /sys/class/graphics/fb0/virtual_size`）为准，三方资料（官网规格、dtb compatible）可能不一致。
