# 启动 logo 更换（logo 分区）

ABL 在开机阶段从 `logo` 分区读取位图并显示：开机 logo、fastboot 界面、充电画面等。
本文是规格说明书式的说明，不绑定具体工具实现。

## 屏幕与位图规格

- 面板分辨率 **1080x2244**（竖屏）。
- 分区里的位图必须是**标准 BMP**：54 字节头部、24bpp、BI_RGB 无压缩、底向上（bottom-up）。
- 一张全屏位图字节数 = 54 + 1080×3×2244 = 7,270,614。

## 分区结构

`logo` 分区（32 MiB）布局如下：

| 偏移 | 内容 |
|------|------|
| 0x0000 – 0x3FFF | 全零 |
| 0x4000 | 魔数 `LOGO!!!!`（8 字节） |
| 0x4008 | 10 个 u32 小端整数：**前 5 个是偏移、后 5 个是大小**，单位都是 512 字节块（大小 = ceil(位图字节数 / 512)） |
| 0x4200 起 | 5 张 BMP，各自占用大小字段指定的槽位，位图末尾到槽位末尾补零 |

注意：魔数后紧跟的第一个偏移量低字节恰好像是第 5 个 `!`（例如 0x21），肉眼 hex 查看时容易把魔数误读成 `LOGO!!!!!`，实际只有 8 字节。

## 五个槽位

| 槽 | 尺寸 | 用途 |
|----|------|------|
| 0 | 1080x2244 | 开机 logo |
| 1 | 1080x2244 | fastboot 界面（清空后 fastboot 会退回文本模式，反而显示更多信息） |
| 2 | 300x2160 | 充电画面 |
| 3 | 1080x2244 | 开机 logo（解锁态显示的那份） |
| 4 | 1080x2244 | "The system has been destroyed"（系统损坏画面，建议保留） |

## 操作流程

1. **备份**。从官方固件包取 `logo.img`，或直接 `dd` 出整个 logo 分区（分区前 31,044,608 字节为有效内容，其余为零填充）。两份互为印证。
2. **解析**。按上表读头部拿 5 个偏移/大小（×512），用 `binwalk` 或手写脚本定位 BMP。替换前应确认：读出的 BMP 尺寸是 1080x2244（以分区为准，不要信设备树里的面板 compatible——本机 dtb 借用了别型号的面板驱动）。
3. **制作新图**。任意图像工具（Krita/GIMP/Python），画布 1080x2244、黑底，导出为 24bpp BMP。尺寸和位深必须与原槽位一致，否则整图偏移错位、显示花屏。
4. **重打包**。原位替换：把新 BMP 写进对应槽位，槽位剩余部分补零；不要动头部和别的槽位。移除某张图 = 整槽清零。写完做逐字节 diff，确认改动范围只在目标槽位内。
5. **刷入**。进 fastboot（关机后 power + vol-），执行 `fastboot flash logo logo-new.img`，然后 `fastboot reboot`。
6. **回滚**。有问题刷回备份的 stock `logo.img` 即可，不影响系统其余分区。

## 备忘

- fastboot splash（槽 1）清空后，进 fastboot 显示的是带版本/变量信息的文本界面，方便调试。
- 充电画面（槽 2）与开机链路无关，平时看不到就不用动。
- 设备屏幕实际分辨率以分区内 BMP 头和运行时 framebuffer（`cat /sys/class/graphics/fb0/virtual_size`）为准，三方资料（官网规格、dtb 面板 compatible）可能不一致。
