# Mesa 25.0.7 → 26.1.6 性能对比（sirius / Adreno 616）

2026-10-19，设备从 Debian trixie 自带的 Mesa 25.0.7 升级到 trixie-backports 的 26.1.6，
用 glmark2 与 vkmark 做了对比。

## 结论

- **OpenGL（freedreno）提升约 15%**：glmark2 中位 860 → 991。
- **Vulkan（Turnip）基本不变**：vkmark 中位 591 → 594（+0.5%），四个场景逐个持平。
- **合成器没有变慢**。同一合成器下的客户端对照同样只有 GL 提升（+10.6%），VK 持平（+0.2%）。

## 测试条件

GNOME Wayland 会话，窗口模式 1280x720（经合成器呈现）；glmark2 2023.01（GL 4.6）、
vkmark 2025.01（Vulkan 1.3，Turnip）。

为排除干扰，每轮开跑前都满足：电池 ≤33°C、cpu0 ≤36°C 且稳定 60s，停充；
GPU 固定在 504MHz、CPU 用 performance；确认屏幕处于点亮状态（DPMS On）；
两个版本各跑 5 次取中位。

屏幕是否点亮对窗口模式的分数影响很大：同一套 26.1.6，屏幕熄灭时 vkmark 是 666，
点亮后只有 594（差约 12%）。早期未记录这个状态，曾误判为「26.1 合成器变慢」。

## 结果

### 整栈（各 5 次，中位）

| 项目 | 25.0.7 | 26.1.6 | 变化 |
|---|---|---|---|
| glmark2 总分 | 860 | **991** | **+15.2%** |
| vkmark 总分 | 591 | 594 | +0.5% |

### OpenGL 分场景（FPS，中位）

| 场景 | 25.0.7 | 26.1.6 | 变化 |
|---|---|---|---|
| refract | 83.5 | 159.0 | +90% |
| shadow | 517.5 | 696.0 | +35% |
| build (vbo) | 1742.5 | 2095.0 | +20% |
| texture (mipmap) | 1543.5 | 1787.0 | +16% |
| shading (phong) | 1178.0 | 1262.0 | +7% |
| bump (high-poly) | 959.5 | 1019.0 | +6% |
| jellyfish | 755.5 | 796.0 | +5% |
| terrain | 61.0 | 63.0 | +3% |

### Vulkan 分场景（FPS，中位）

| 场景 | 25.0.7 | 26.1.6 | 变化 |
|---|---|---|---|
| vertex | 666 | 672 | +0.9% |
| texture | 635 | 639 | +0.6% |
| shading | 600 | 603 | +0.5% |
| effect2d | 464 | 468 | +0.9% |

### 只换客户端（合成器保持 26.1.6）

用旧版客户端库跑在 26.1.6 的合成器下，把「驱动」和「合成器」两个变量拆开：

| 项目 | 旧客户端 | 新客户端 | 变化 |
|---|---|---|---|
| glmark2 总分 | 861 | **952** | **+10.6%** |
| vkmark 总分 | 593 | 594 | +0.2% |

与整栈结果方向、量级都一致：变的是 GL 客户端，VK 客户端与合成器都没变。

### 同场景 GL vs VK（自写微基准）

glmark2 和 vkmark 的场景不同，总分不能直接比。用同一份网格、同一份着色器、
同一离屏目标（1280x720，不呈现）分别用两个 API 跑：

| 负载 | OpenGL | Vulkan | 差异 |
|---|---|---|---|
| 全屏 + 重片元着色器 | 49.2 fps | 49.0 fps | 持平 |
| 54 万顶点 / 18 万三角形，单次 draw | 268 fps | 380 fps | **VK +42%** |
| 同上，拆成 512 次 draw | 205 fps | 315 fps | **VK +52%** |

即：像素/着色器吞吐两者相同；顶点与 draw 提交 Turnip 更快（每次 draw 开销
OpenGL 约 2.1µs、Vulkan 约 1.1µs）。

### 无合成器（KMS 直出）

停掉合成器、直接以 DRM/KMS 出图（原生 1080x2244）：glmark2 343、vkmark 598，
两次重复完全一致。把 720p 亮屏的 Vulkan 数据按像素数折算，与直出结果相差在 ±10% 内，
说明窗口模式的数字里没有额外的合成开销。

## 解读

- GL 的提升集中在折射、阴影、构建、纹理这些 GPU 负载重的场景，属于 freedreno 客户端的
  真实进步。
- Vulkan（Turnip）在两个版本间没有任何变化，之前「VK 变慢」是屏幕熄灭时的假象。
- 固件未变：GPU 的 `a630_gmu` / `a630_sqe`、WiFi 的 `firmware-5.bin` / `wlanmdsp.mbn`
  在新版包里与旧版完全相同。
